# ERP Industrial — React + Vite

Projeto didático de ERP Industrial desenvolvido com React e Vite.

## Como executar

1. Instale o Node.js.
2. Abra esta pasta no VS Code.
3. No terminal, execute:

```bash
npm install
npm run dev
```

4. Abra no navegador o endereço local mostrado pelo Vite (normalmente `http://localhost:5173`).

## Organização

- `src/App.jsx`: componente principal e controle dos módulos.
- `src/App.css`: estilos da aplicação.
- `src/index.css`: estilos globais.
- `src/main.jsx`: ponto de entrada do React.
- `src/components/`: componentes reutilizáveis (botões, cartões e menu lateral).

A pasta `node_modules` não está incluída. Ela será recriada pelo comando `npm install`.
